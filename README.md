# TNT go Touchpad

让 Smartisan TNT go 扩展坞的触摸板在 macOS 上可用。

## 背景

TNT go 的键盘/触摸板是一套第三方 HID 设备(VID `0x31CE` / PID `0x5101`)。macOS 只把它识别成普通键盘,不会为其中的触摸板创建指针服务 —— 所以触摸板插上没有任何反应。

本项目是一个菜单栏应用(用户态驱动):直接读取触摸板的原始多点触控 HID 报告,翻译成 macOS 的 CGEvent 指针事件。不需要内核扩展,不污染系统。

## 功能

- 单指移动(带速度加速;拖拽窗口时自动切 1:1,不飞)
- 物理左键 + 轻点点击(可在菜单关闭)
- 双指滚动(速度可调;默认跟随系统「自然滚动」设置,也可反转)
- 双指捏合缩放(合成原生 magnify 手势)
- 三指轻扫:左右滑切换桌面、上滑打开调度中心、下滑显示应用窗口(与原生触摸板一致)
- 菜单栏实时调参,改动即时生效,无需重启
- 登录自启动开关
- 一键卸载:注销登录项、清理 TCC 授权记录与开发证书、移到废纸篓,系统无残留

## 构建

需要 Xcode Command Line Tools:

```
./build.sh
```

产出 `TNTgo Touchpad.app`。

## 安装与授权

1. 把 `TNTgo Touchpad.app` 拷到 `/Applications` 后打开;
2. 首次使用需要在 **系统设置 → 隐私与安全性** 里允许两个权限:
   - **辅助功能** —— 发送指针移动/点击事件所需;
   - **输入监控** —— 触摸板报文和键盘共用同一个 HID 复合接口,读取它必须持有此权限,无法绕开。

权限没给时菜单栏会显示「错误(重试中…)」,程序每 5 秒自动重试,授权后即恢复,无需重启。

另外,**首次使用三指轻扫**时系统会再问一次「允许控制 System Events」—— 三指手势(切桌面/调度中心/应用窗口)需要经 System Events 发送系统快捷键,点允许即可,同样只有一次。

## 关于签名(为什么重编译后权限不失效)

macOS 的 TCC 按应用签名匹配授权。ad-hoc 签名(无证书)每次编译指纹都会变,权限随编译失效。因此 build.sh 默认用名为 **TNTgo Touchpad Dev** 的自签名证书签名,授权按证书匹配,重编译不再失效。

证书不存在时会自动退回 ad-hoc 签名 —— 功能完全正常,只是每次重编译要重新授权一次。

想在自己的机器上创建同名证书:打开「钥匙串访问 → 证书助理 → 创建证书」,类型选 **代码签名**,命名为 `TNTgo Touchpad Dev` 即可;或把 build.sh 里的 `IDENTITY` 改成你已有的签名身份。

## 图标

图标由 `make-icon.swift` 程序化绘制(TNT go 黑底白字风格),不依赖任何图片素材:

```
swift make-icon.swift        # 生成 icon_1024.png
```

`assets/icon.icns` 缺失时,build.sh 会自动把 `icon_1024.png` 转成 icns(sips + iconutil)。修改图标后删掉 `assets/icon.icns` 再跑 `./build.sh` 即可重新生成。

## 项目结构

```
main.swift        全部实现:HID 读取 + 手势识别 + 菜单栏 UI
build.sh          构建 .app(含图标生成与签名)
make-icon.swift   应用图标绘制
assets/icon.icns  应用图标(由上面的脚本产物转换而来)
```

## 卸载

菜单栏图标 → 卸载并移到废纸篓。会自动注销登录项、清理 TCC 记录、删除开发证书。

## 已知限制

- 仅针对 TNT go 的键盘/触摸板复合设备做了报文解析,其他触摸板不适用;
- 触摸板硬件只在被触摸时上报,「已连接」状态以 HID 设备打开成功为准;
- 需要 macOS 13+。
